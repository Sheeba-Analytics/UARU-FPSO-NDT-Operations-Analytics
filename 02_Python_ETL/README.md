# Python ETL

This folder contains the Python ETL workflow developed for the UARU FPSO NDT Operations Analytics project.

## Main Tasks

- Import multiple Excel source files
- Consolidate inspection datasets
- Clean and standardize data
- Validate data quality
- Apply business rules
- Correct invalid dates
- Generate the final staging dataset
- Export the cleaned data for SQL Server loading

> **Note**
>
> The original datasets are not included because they contain confidential company information.
