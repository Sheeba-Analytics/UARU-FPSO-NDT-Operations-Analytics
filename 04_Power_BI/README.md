# Power BI Dashboard

This folder contains the Power BI dashboard developed for the UARU FPSO NDT Operations Analytics project.

## Dashboard Pages

- Executive Overview
- Operational Trends
- Operational Analysis
- Method Drill-through
- Custom Tooltip

## Dashboard Features

- Interactive slicers
- Drill-through analysis
- Custom tooltips
- KPI cards
- Dynamic reporting period
- Operational trend analysis
- Method performance analysis
- Module analysis

> The original Power BI (.pbix) file is not included because it contains confidential operational data.
